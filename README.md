# Moon Visual

Визуальный клиентский мод для Minecraft (Fabric 1.21.1): HUD, частицы, анимации,
оптимизатор FPS, темы и два языка. Никаких изменений геймплея — только картинка.

## Статистика
- **174 функции** в реестре (9 категорий)
- **~103 уже работают**, остальные отмечены в GUI как «Soon» (появятся в следующих версиях)

## Что уже работает
- **GUI на правый Shift**: категории, тогглы, слайдеры, палитры цветов, селекты, поиск, подсказки, анимация открытия.
- **HUD**: ватермарка (4 стиля), FPS, пинг, координаты, направление, биом, время (2 стиля), CPS, IP, память, скорость, инфо о предмете, прочность, броня, HP, голод, зелья, клавиши (3 стиля), arraylist (4 позиции), Target HUD (4 стиля), числа урона (3 стиля), кастомный прицел (5 стилей), hit-crosshair, виньетка при низком HP.
- **Эффекты**: частицы удара и крита (10 стилей: Spark, Moonlight, Blood, Bloom, Star, Void, Frost, Ember, Astral, Sakura), kill-эффект, круг прыжка (3 стиля), след при беге, шаги, приземление, лунная аура (3 стиля), вихрь зелья, свечение, звук попадания, лунный след косметики (4 стиля).
- **Оптимизация**: лимит FPS, FPS в фоне, отключение облаков/теней, сила частиц, blend биомов, дистанция сущностей, мипмапы, пресет графики, очистка памяти, адаптивное качество, прорисовка, отключение пульсации Darkness, динамического FOV.
- **Камера**: FOV, зум (клавиша C) с силой и плавностью.
- **7 тем** (Moonlight, Dark, Light, Bloodmoon, Sakura, Neon, Midnight), радужный акцент, **2 языка** (EN/RU).
- Настройки сохраняются в `config/moonvisual.json`, есть автосохранение.

## Сборка
1. Установи **JDK 21**.
2. Если нет Gradle: `gradle wrapper` (нужен установленный Gradle 8+), либо открой проект в IntelliJ IDEA — он всё сделает сам.
3. Собери: `./gradlew build`
4. Готовый jar появится в `build/libs/moonvisual-0.1.0.jar` — кидай в папку `mods`.

## Клавиши
- **Right Shift** — открыть Moon Visual
- **C** — зум

## Принцип
Moon Visual — только визуал и HUD. В проект не включаются функции, которые
серверы считают нечестными преимуществом (ESP, X-Ray и т.п.).
